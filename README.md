# 📚 쑥쑥 영어 독서 통장

두 아이(민건, 민결)가 매일 영어책을 3권씩 읽고 스탬프를 모으는 **단일 파일 웹 앱**입니다.
`BookAccount.html` 하나만 있으면 되고, 외부 요청이 전혀 없어 **인터넷 없이도** 바로 실행됩니다.

## 실행 방법

`BookAccount.html`을 브라우저로 열면 끝입니다. (설치·빌드·서버 불필요)

태블릿에서 쓰려면 파일을 아이 기기로 옮긴 뒤 브라우저에서 열고 **홈 화면에 추가**하면 앱처럼 사용할 수 있습니다.

## 주요 기능

- **아이별 개별 관리** — 상단 탭으로 전환, 각자의 스탬프판·기록·오늘 미션이 독립 저장
- **하루 미션** — 영어책 3권을 모두 체크해야 스탬프 버튼이 활성화
- **하루 1스탬프 제한** — 날짜 검증으로 중복 방지, 스탬프 완료 시 독서 체크 잠금
- **30칸 스탬프판** — 🦊 🐼 🦖 🧸 🌟 🐾 🚀 🍎 중 아이가 좋아하는 아이콘 선택
- **30개 달성 축하** — 콘페티 애니메이션과 함께 선물 교환 안내 팝업
- **부모님 안심 잠금** — 덧셈 퀴즈를 풀어야 진입하는 관리 모드 (스탬프 수동 조절, 오늘/전체 리셋)
- **효과음** — 외부 음원 파일 없이 Web Audio API로 직접 합성
- **자정 자동 롤오버** — 앱을 켜둔 채 날짜가 바뀌어도 오늘 미션이 새로 시작

## 데이터 저장

기록은 브라우저 `localStorage`(`kids_reading_stamps_v4`)에 저장됩니다.
**기기·브라우저별로 저장되므로 여러 기기 간에는 공유되지 않습니다.** 한 기기에서 사용하는 것을 권장합니다.

## 기술 스택

의존성 없음. HTML + CSS + 순수 JavaScript 단일 파일.
