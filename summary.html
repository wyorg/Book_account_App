종이 독서 통장을, 매일 쓰기 좋게

아이의 독서 습관은 "오늘 몇 권 읽었는지"를 매일 눈으로 확인하고 작은 보상으로 이어줄 때 자리잡습니다. 그런데 종이 스탬프판은 잃어버리기 쉽고, 흔한 학습 앱은 로그인·광고·결제가 끼어들어 아이에게 그대로 쥐여주기 어렵습니다.

이 앱은 로그인도 광고도 없이, 아이별로 오늘의 미션 3권을 체크하고 스탬프 한 칸을 채우는 단순한 흐름만 남겼습니다. 30칸을 다 모으면 부모와 약속한 보상으로 이어지고, 아이가 숫자를 임의로 못 바꾸도록 부모 전용 잠금을 두었습니다.

핵심 기능

아이는 쉽게, 부모는 안심하게

✅

하루 미션 3권

책 3권을 모두 체크해야 스탬프 버튼이 열립니다. 하루 1칸만 채울 수 있고, 찍고 나면 그날 기록은 잠겨 수정되지 않습니다.

🎁

30칸 스탬프판 + 보상

칸을 다 채우면 색종이가 쏟아지는 축하 화면과 함께 보상 안내가 뜹니다. 날짜별 획득 기록도 쌓여 한눈에 보입니다.

🔒

부모 안심 잠금

스탬프 수동 조절·초기화는 간단한 덧셈 문제를 풀어야 들어가는 부모 모드 안에만 있어, 아이가 혼자 조작할 수 없습니다.

🎨

구성원 커스터마이징

최대 6명까지 이름을 직접 추가·수정하고, 저마다 테마 색과 좋아하는 이모지 스탬프(🦊🐼🦖…)를 고를 수 있습니다.

🔊

내장 합성 효과음

MP3 한 개 없이 Web Audio API로 체크·스탬프·축하 소리를 즉석에서 합성합니다. 그래서 오프라인에서도 소리가 납니다.

📱

오프라인 · 홈화면 설치

단일 HTML + 로컬 저장이라 비행기에서도 열리고, PWA로 태블릿 홈 화면에 앱처럼 설치됩니다. 자정이 지나면 오늘 미션이 자동 갱신됩니다.

에이전트가 만든 과정

빈 파일 한 장에서 배포까지

사람이 넘긴 것은 "이 기획서 참고해서 만들어줘"라는 한 문장과 참고 파일뿐이었습니다. 나머지는 에이전트가 판단하고 실행했습니다.

1

맥락 복구

건네받은 파일이 0바이트라, 같은 시각 내려받은 다른 파일에서 기획과 초안 코드를 찾아 작업 기준으로 삼았습니다.

2

치명적 버그 수정

초안에는 confettiArray가 정의되지 않아 30개 달성 순간 앱이 멈추는 버그가 있었습니다. 원인을 짚어 콘페티 생성 로직을 직접 다시 작성했습니다.

3

오프라인용 재설계

초안은 React·Tailwind·Babel을 CDN에서 불러와 인터넷이 없으면 흰 화면이 됐습니다. 아이 태블릿용이라는 맥락에 맞춰 외부 요청 0개의 순수 HTML/CSS/JS 단일 파일로 다시 썼습니다.

4

브라우저 자동 검증

실제 브라우저에서 3권 체크 → 스탬프 → 하루 1회 잠금 → 부모 모드 퀴즈 → 30개 콘페티 → 저장/복원까지 클릭해 보며 동작과 콘솔 오류 0건을 확인했습니다.

5

배포 자동화

git init → 커밋 → GitHub push 후, GitHub Pages·.nojekyll·index.html 정리와 PWA 매니페스트·홈화면 아이콘까지 붙여 공개 주소로 띄웠습니다.
